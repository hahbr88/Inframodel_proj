# VMware 환경 구성

## 개요

본 문서는 레거시 온프레미스 환경 구축을 위한 VMware 가상머신 생성 기준을 정의한다.

모든 팀원은 동일한 서버 구성과 자원 할당 기준을 적용하여 환경을 구축해야 한다.

본 단계에서는 Ubuntu Server 24.04.4 LTS 기반 가상머신 생성 및 운영체제 설치를 수행한다.

---

# 구축 대상 서버

레거시 온프레미스 환경은 총 4대의 서버로 구성한다.

| 서버명        | 역할              |
| ------------- | ----------------- |
| legacy-ops-01 | 운영 서버         |
| legacy-web-01 | 웹 서버           |
| legacy-app-01 | 애플리케이션 서버 |
| legacy-db-01  | 데이터베이스 서버 |

---

# 운영체제 기준

모든 서버는 아래 운영체제를 사용한다.

| 항목      | 값                        |
| --------- | ------------------------- |
| 운영체제  | Ubuntu Server 24.04.4 LTS |
| 설치 방식 | Server                    |
| 업데이트  | 최신 패키지 적용          |

---

# 서버 자원 할당 기준

## legacy-ops-01

운영 서버는 VPN, DNS, NTP 등 공통 운영 서비스를 담당한다.

| 항목    | 자원   |
| ------- | ------ |
| CPU     | 1 Core |
| Memory  | 2 GB   |
| Storage | 10 GB  |

---

## legacy-web-01

웹 서버는 사용자 요청을 수신하는 서버이다.

| 항목    | 자원   |
| ------- | ------ |
| CPU     | 1 Core |
| Memory  | 2 GB   |
| Storage | 20 GB  |

---

## legacy-app-01

애플리케이션 서버는 서비스 로직을 처리하는 서버이다.

| 항목    | 자원   |
| ------- | ------ |
| CPU     | 2 Core |
| Memory  | 4 GB   |
| Storage | 30 GB  |

---

## legacy-db-01

데이터베이스 서버는 서비스 데이터를 저장하고 관리하는 서버이다.

| 항목    | 자원   |
| ------- | ------ |
| CPU     | 2 Core |
| Memory  | 4 GB   |
| Storage | 60 GB  |

---

# 가상머신 생성

각 서버별로 VMware 가상머신을 생성한다.

생성 시 운영체제는 Ubuntu Server 24.04.4 LTS를 사용한다.

서버별 CPU, Memory, Storage는 관리대장 기준 자원을 적용한다.

---

# 운영체제 설치

Ubuntu Server 24.04.4 LTS ISO를 이용하여 설치를 진행한다.

설치 완료 후 최초 로그인까지 정상 수행되어야 한다.

---

# 설치 확인

로그인 후 아래 명령어로 운영체제 버전을 확인한다.

```bash
cat /etc/os-release
```

확인 결과에 Ubuntu 24.04.4 LTS 정보가 표시되어야 한다.

---

# 서버 생성 완료 확인

생성된 가상머신 목록을 확인한다.

| 서버명        |
| ------------- |
| legacy-ops-01 |
| legacy-web-01 |
| legacy-app-01 |
| legacy-db-01  |

모든 서버가 정상적으로 부팅되어야 한다.

---

# 구축 완료 기준

다음 항목을 모두 만족하면 VMware 환경 구성이 완료된 것으로 판단한다.

- Ubuntu Server 24.04.4 LTS 설치 완료
- 서버 4대 생성 완료
- 서버 정상 부팅 확인
- 운영체제 로그인 확인
- 서버별 자원 할당 적용 확인

## VScode 다운로드 및 환경설정

[여기](vscode_settting.md)를 클릭해서 확인


## 레포지토리 클론

레포 클론할 VM에 git 설치

```bash
sudo apt update
sudo apt install git -y
```

설치확인
```bash
git --version
```

홈디렉토리(~) 에서 아래와 같이 명령어 입력

```bash
mkdir docker
cd docker
git clone https://github.com/hahbr88/Inframodel_proj.git
```
